# DSA0116 – Assignment 4 (CO4)

## Folder structure
- Task01: Staff hierarchy and runtime polymorphism
- Task02: University people hierarchy and virtual inheritance
- Task03: Derived/member class constructors and destruction order
- Task04: Account pointers, virtual functions and virtual destructor
- Task05: Cart objects, pointers, references and this pointer
- Task06: Vehicle rental fleet using an extensible abstract hierarchy

Each task folder contains:
- main.cpp – standalone C++17 program
- run-output.txt – expected output for the sample run

## Compile and run
Use g++ with C++17 and warnings enabled:

```bash
g++ -std=c++17 -Wall -Wextra main.cpp -o main
./main
```

Run the command from the relevant Task folder.

## Notes
The programs are sample implementations of the coding portions of Assignment 4. Tasks that ask for written diagnosis, UML diagrams, access tables, pseudocode, predictions and complexity analysis are report components and are not represented as separate executable programs here. The run-output.txt files contain expected outputs derived from the source; capture actual local execution screenshots for evidence before submission.
