# Assignment 3 – CO3

This folder contains answers and C++ programs for Q1–Q7.

## Folders
- `Q1`: Constructors and constructor overloading
- `Q2`: Deep copy, copy assignment and destructor
- `Q3`: Dynamic seat map and object lifetime
- `Q4`: Money arithmetic and stream operators
- `Q5`: Increment, comparison and subscript operators
- `Q6`: Text class and operator overloading rules
- `Q7`: Complex numbers and impedance calculations

## Compile and run
Use a C++17 compiler. Example:

```bash
g++ -std=c++17 -Wall -Wextra Q1/main.cpp -o q1
./q1
```

Change Q1 to the question folder you want to run. Each source file is a separate program.

**Student details:** Add your name and register number before submission. Use your own compiler version and run the programs on your machine.
